# 📜 موقع القوانين وعرض الأنظمة

هذا المشروع عبارة عن موقع ويب حديث واحترافي مصمم خصيصاً لعرض قوانين وأنظمة خوادم (Servers) الألعاب والرول بلاي بشكل منظم وجذاب.

## ✨ مميزات الموقع
- **تصميم عصري (Premium)**: يعتمد على ألوان داكنة وتأثيرات زجاجية (Glassmorphism) مريحة للعين وتعطي طابعاً فخماً.
- **ديناميكية كاملة**: يمكن تعديل جميع النصوص، القوانين، والصور بسهولة من ملف `config.js` دون الحاجة لخبرة برمجية.
- **تأثيرات بصرية**: خلفيات متحركة وقوائم جانبية تفاعلية.
- **متجاوب**: يعمل بشكل ممتاز على جميع أحجام الشاشات.

### 🛠️ طريقة التعديل السريع
1. توجه إلى ملف `config.js`.
2. عدل على النصوص والروابط داخل الملف بما يناسب سيرفرك.
3. احفظ الملف وسيتحدث الموقع تلقائياً.
